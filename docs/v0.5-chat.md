# MyPhone v0.5 — 端到端加密聊天

## 概述

在通话 E2EE 基础上新增 **1:1 加密聊天**：文字/表情走现有 WS 中继（端到端加密），
图片/文件/视频走 WebRTC DataChannel 点对点直传。文件只存在双方客户端，
服务器绝不见文件内容。

## 核心决策

| 项 | 决策 |
|---|---|
| 加密栈 | 扩展自研 `CryptoManager`（X3DH + 完整双棘轮），不引入 libsignal |
| 文字送达 | WS 中继 + Redis 短期离线队列（24h TTL，服务器只见密文） |
| 文件传输 | WebRTC DataChannel P2P 直传，服务器只中继信令 |
| 文件存储 | 仅客户端 app 私有目录（AES-256-GCM 加密） |
| 阅后即焚 | Signal 模型：`expires_in_seconds` 已读后起表，到期双方删 |

## 新增模块（mobile）

- `lib/core/crypto/chat_ratchet.dart` — 完整 Double Ratchet 状态机
  - 解密侧 DH 棘轮、乱序 skipped-key 缓冲、AAD 会话绑定、真随机 nonce
- `lib/core/crypto/chat_session_manager.dart` — X3DH 建立 + prekey bundle + 会话持久化
- `lib/core/network/chat_signal.dart` — 聊天信令信封（复用 `{type,from,to,payload}`）
- `lib/core/network/signaling_client.dart` — 分发修复：未知 type → `chatSignals` 流
- `lib/features/chat/` — `chat_state.dart`、`chat_session_controller.dart`、
  `chat_file_transfer_manager.dart`、screens/widgets
- `lib/core/storage/database.dart` — schema v4：`conversations`/`messages`/
  `message_attachments`/`chat_sessions`

## 服务器改动（Go）

- `internal/api/keys.go` — `GET /v1/keys/bundle/{userID}`（聚合 identity+signed-prekey+
  一次性 prekey，`FOR UPDATE SKIP LOCKED` 原子置 used）
- `internal/signaling/hub.go` — `chatMessage` 离线入 Redis 队列（TTL 24h + 去重），
  上线 FIFO 冲刷；**通话中继零改动**
- `internal/models/db.go` — `idx_pre_keys_used` 索引

## 协议要点

- 聊天信令 `type` 含 `chatInit/chatMessage/chatReceipt/chatTyping/chatDisappearing/
  chatFileOffer/Answer/Ice/Done`
- 会话建立：发起方取 bundle → 验签 → X3DH（4-DH，无一次性 prekey 回退 3-DH）
- 文件密钥：逐文件随机 AES-256-GCM key，经棘轮加密的 `chatMessage` 端到端送达
- 阅后即焚：明文消息体携带 `expires_in_seconds`，服务器不可见；已读起表

## 测试清单（验收）

### 单元测试（`flutter test`）
- 棘轮：加解密往返 / 乱序 / DH 棘轮多轮 / 篡改失败不回卷 / nonce 唯一 /
  AAD 绑定 / 序列化续会话 / 帧字节往返
- X3DH：发起/响应双方 root key 一致

### 手动 e2e（双设备/模拟器）
- [ ] 建立会话：A 给 B 发首条消息，B 解密显示，指纹展示
- [ ] 在线文字：双方在线秒达
- [ ] 离线队列：B 离线，A 发，B 上线即收到；24h 过期
- [ ] 图片/视频/文件：数据通道传输，进度条，B 端 `plaintext_sha256` 校验，
      服务器日志无文件字节
- [ ] 阅后即焚：设 5s → 已读后双方删行+删媒体，重启不复活
- [ ] 重启持久化：杀进程重开，会话存活，消息可解
- [ ] 重装换身份：指纹变更告警
- [ ] 后台收消息：通知（无内容预览），点开进入会话解密

## 待办 / 已知限制

- 纯 Dart AES 大文件性能：v0.5 建议限 200MB；后续可上原生编解码
- 大文件走数据通道需双方在线，离线自动重试（presence 触发）
- 群聊 / 多设备：明确不做（v0.4 非目标延续）
