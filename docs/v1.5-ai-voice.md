# v1.5 AI 语音通话（哪吒/智能体）设计文档

聊天页电话按钮：普通联系人走现有通话；机器人（哪吒）走 **ASR→Agent→TTS 实时全双工语音通话**，通话中识别文本 / Agent 回复 / 动作卡片全部回流聊天页成为消息。

## 架构

```
手机 App ──WS(单例)──▶ myphone-server ──WS 桥──▶ media-agent (Pion WebRTC)
                                                    │ 入站 Opus RTP → ASR provider
                                                    │ Agent 文本 → ①TTS 出站 ②chatMessage 回流 ③字幕
                                                    └─ 零本地 Opus 编解码（纯 Go，CGO_ENABLED=0）
```

- **信令**：复用 WS 单例；`agentInit / agentSignal / agentHangup / agentReady / agentTranscript` 走 `chatSignals` 流。
- **媒体**：media-agent 每用户一个 PeerConnection；入站语音帧直转 ASR，TTS 帧经 `TrackLocalStaticRTP` 出站播放。
- **内容回流**：Agent 文本/动作走 bot 明文 `chatMessage`（`plaintext:true`）落库，动作渲染为卡片（`kind=action` + `agent_payload`）。
- **会话隔离**：AI 会话与真实通话互斥（`callStateProvider` 非空时 AI 会话不启动；AI 中收真实来电自动挂 AI 会话）。
- **不加密**：与智能体的对话明文（用户明确要求，非机密日常任务）。

## 服务端部署

### 1. 环境变量（`/etc/myphone/myphone.env`，install-deps.sh 已生成）

| env | 用途 |
|---|---|
| `AGENT_MEDIA_WS_URL` | myphone-server 出站桥 → 媒体端点 `ws://127.0.0.1:8090/bridge` |
| `AGENT_BRIDGE_TOKEN` | 桥接共享密钥（随机生成） |
| `AGENT_LISTEN_ADDR` | 媒体端点监听 `127.0.0.1:8090`（仅回环） |
| `AGENT_ASR_URL` | 外部 ASR（WS 流式） |
| `AGENT_TTS_URL` | 外部 TTS（HTTP JSON → Opus 帧） |
| `AGENT_TEXT_URL` | Agent 文本（缺省回退 `BOT_AGENT_URL`） |
| `AGENT_STUN_URL`/`AGENT_TURN_URL`/`AGENT_TURN_USERNAME`/`AGENT_TURN_CREDENTIAL` | 媒体端点 ICE（复用 coturn） |

**缺省（ASR/TTS/Agent 留空）**：媒体端点回退本地回声——仍可全链路演示（字幕/文本/动作卡片），但无真实语音。

### 2. 构建与部署

```bash
# 开发机
bash deploy/build-server.sh        # 产物：artifacts/myphone-server + artifacts/media-agent
scp deploy/artifacts/myphone-server root@<公网IP>:/opt/myphone/
scp deploy/artifacts/media-agent root@<公网IP>:/opt/myphone/

# 服务器
cd /root/myphone-deploy
bash deploy-server.sh              # 安装 media-agent.service 并启动
bash verify.sh                     # 自检两服务 /health
```

接入真实提供方后编辑 `myphone.env` 填 URL → `systemctl restart media-agent`。

### 3. 安全组

- 媒体端点 `8090` 仅回环监听，**不需要**公网放行。
- WebRTC 媒体面复用 coturn：已放行 `3478/tcp+udp`、`49152-65535/udp`（阿里云安全组）。

## 方案 A：接入 qwen-audio-agent 语音引擎（v1.50+）

手机语音不改动（仍 WebRTC），media-agent 经 **libopus 转码**后接
[qwen-audio-agent](https://github.com/QwenAudio/qwen-audio-agent) 的 Gateway：

```
手机 ──WebRTC(Opus)──▶ myphone-server(桥)──▶ media-agent(Pion)
                                                │ Opus→PCM16k → Gateway audio.append
                                                │ Gateway audio.delta(PCM24k)→Opus → 出站
                                                │ transcript.final → agentTranscript(字幕)
                                                │ task.* → chatMessage(动作卡片)
```

**libopus 转码层**（`internal/agent/media/opus_codec.go`，cgo）：
- 入站：手机 Opus(48k) → 解码 → 降采样 PCM16k → Gateway `audio.append`
- 出站：Gateway PCM24k → 升采样 48k → 编码 Opus → `PlayFrame` 回手机
- 仅 media-agent 需 CGO 构建（libopus-dev/opusfile-dev）；myphone-server 仍纯静态。

**Gateway 客户端**（`internal/agent/media/gateway_client.go`）：
- 连 `AGENT_GATEWAY_URL`（默认 `ws://127.0.0.1:3101/api/realtime?sessionId=user_personal`）
- 事件：`connect` / `audio.append` / `interrupt`（客户端→服务端）
  `voice.ready` / `audio.delta` / `transcript.final` / `response.*` / `task.*`（服务端→客户端）
- qwen-audio-agent `QWEN_AUDIO_AGENT_IDENTITY_MODE=personal` 时免鉴权。

**配置**（`/etc/myphone/myphone.env`）：
```dotenv
AGENT_GATEWAY_URL=ws://127.0.0.1:3101/api/realtime
# 可选后台 Agent（让哪吒执行工具/多步任务）：
AGENT_PROTOCOL=hermes
HERMES_BIN=/usr/local/bin/hermes
```

未配置 `AGENT_GATEWAY_URL` 时 media-agent 回退原 ASR/Agent/TTS 三件套。

## 客户端

- `agent_call_state.dart` — AgentCallNotifier（复用 WS 单例，不 connect）。
- `agent_call_screen.dart` — 全屏 AI 通话界面（头像/字幕/静音/挂断/扬声器）。
- 输入栏最左电话按钮：bot → `/agent-call`；普通 → `/call`。
